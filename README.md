# Capricho Gourmet

## Descripción del proyecto

Capricho Gourmet es un sitio web desarrollado como parte de la asignatura de Programación Web. El proyecto representa un pequeño negocio dedicado a la elaboración y venta de dulces y productos de repostería.

El sitio fue desarrollado utilizando HTML y CSS, incorporando diferentes elementos trabajados durante la asignatura, como estructura semántica, SEO básico, Flexbox, CSS Grid, transiciones, animaciones, diseño responsive y tema claro/oscuro.

## Vistas del sitio

El proyecto cuenta con las siguientes páginas principales:

- **Inicio:** presenta el negocio mediante una sección destacada con una animación de entrada.
- **Sobre nosotros:** muestra información sobre Capricho Gourmet, sus características, filosofía y esencia.
- **Productos:** presenta diferentes productos mediante tarjetas con imágenes, descripciones y precios.
- **Contacto:** incluye información de ubicación, horario de atención y un formulario de contacto.
- **Iniciar sesión:** contiene un formulario para iniciar sesión, opción de recordar la cuenta y recuperación de contraseña.
- **Recuperar contraseña:** permite introducir un correo electrónico para simular una solicitud de recuperación.
- **Registro:** permite simular la creación de una cuenta mediante correo y contraseña.

## Productos

Entre los productos presentados en el sitio se encuentran:

- Bombones de chocolate con dulce de leche.
- Bombones de chocolate blanco.
- Ensalada fría.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Características principales

- Diseño responsive para diferentes tamaños de pantalla.
- Navegación entre las diferentes páginas del sitio.
- Uso de Flexbox para la organización de elementos.
- Uso de CSS Grid en la sección de información.
- Tarjetas de productos con efecto hover.
- Animación de entrada en la página de inicio.
- Formularios con validación nativa de HTML5.
- Tema claro y tema oscuro.
- Metaetiquetas básicas de SEO.
- Uso de etiquetas semánticas como `header`, `nav`, `main`, `section`, `article` y `footer`.
